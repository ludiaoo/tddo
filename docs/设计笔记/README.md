## 一句话说明「参考模型」这个词

笔记里反复出现的"参考模型"指**问题形式的出处**（多卡多机、双向载荷、时空禁飞区，见 `README.md` 末节），
它的作用是两点：① 提供一套已成型的符号与约束，省去自造定义；② 提供一组公开报告值，用来做外部校验。
**本项目的求解器、评估器、变量重构、全部实验与结论都是自己做的**——笔记里每一条结论都标了检验强度，
也标了它在什么条件下会失效。

  写「全量」的是 16 算例 × 10 种子。两者不可混用（本项目为此返工过两次）。
